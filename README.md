# Smart RollCall – AI & DS 🏛️

**Smart RollCall** is a web-based attendance and student gate pass / permission management system tailored for the **Department of Artificial Intelligence & Data Science (AI & DS)**.

## 🚀 Key Portals & Features

- **Home / Hub (`index.html`)**: Central landing interface directing users to respective portals.
- **Attender Portal (`attender.html`)**: 
  - QR / Scanner and Gate verification
  - Real-time roll call check-in/check-out
- **HOD Panel (`hod.html`)**: 
  - Administrative oversight and permission approvals
  - Consolidated attendance reports and student records analytics

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla ES6+)
- **Styling**: Google Font (Poppins), responsive glassmorphic UI design
